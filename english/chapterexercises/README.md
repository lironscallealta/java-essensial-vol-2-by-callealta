# Chapter Exercises

## 1. Greetings by hour

Given an hour from 0 to 23, print a greeting. Use “Good morning” before 12, “Good afternoon” from 12 through 17, and “Good evening” from 18 onward.

1. Write the decision with an `if / else if / else`.
2. Rewrite it with a nested ternary.
3. Try 9, 12, and 18. For each hour, write down which conditions Java evaluates before choosing the greeting.

## 2. File permissions

Use `0001` for read, `0010` for write, and `0100` for execute. Ana has write and execute permissions.

1. Combine Ana's permissions with `|` and write the result in binary.
2. Use `&` to check each permission. Line up the bits and mark any column with a `1` in both numbers.
3. Use `!= 0` to print whether each permission is enabled.
4. Add read permission. Predict which output changes, then run your code.
