# Coding Task 2 — Pythagorean theorem

Read two `double` values from the console and display the hypotenuse. For inputs 3 and 4, print `c = 5.0`.

- Throw an `IllegalArgumentException` for a negative value.
- Catch a `NumberFormatException` or an `InputMismatchException` for non-numeric input.
- Explain each failure with a clear message and comment each line of the solution.
