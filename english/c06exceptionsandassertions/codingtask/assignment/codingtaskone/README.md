# Coding Task 1 — Shapes with exceptions

Extend the Shapes exercise from Chapter 5. Read one to three integers from the command line and use the existing shape calculator for valid dimensions.

- A negative dimension, no arguments, or more than three arguments must produce an `IllegalArgumentException`.
- An argument that cannot be parsed as an integer must produce a `NumberFormatException`.
- Catch each exception and display a message explaining the problem, followed by the exception type caught.
