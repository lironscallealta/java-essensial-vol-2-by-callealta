# Chapter 5 — Other Class Features

This chapter is in progress. This guide covers the examples added so far.

## Suggested study order

1. **Static members**: run [StaticExample.java](statickeyword/StaticExample.java). Compare the shared counter with each object's serial number. The comment also explains static nested classes. [SomeOtherClass.java](statickeyword/SomeOtherClass.java) accesses the counter from another class. Run [TestingStatic.java](statickeyword/TestingStatic.java) separately to see its initial value without creating any objects.
2. **Math and System**: run [TheMathClassAndTheSystemClass.java](utilityclasses/TheMathClassAndTheSystemClass.java). Access static members through their class names.
3. **Static imports**: run [StaticImports.java](staticimports/StaticImports.java). Use PI, max and out without writing their declaring class names.
4. **Wrapper classes**: read [WrapperClass.java](wrapperclasses/WrapperClass.java). Compare int and Integer, boxing and unboxing. This class has no main method.
5. **The final keyword**: read [TheFinalKeyword.java](finalkeyword/TheFinalKeyword.java) for final classes, methods and fields. [StudentFinal.java](finalkeyword/StudentFinal.java) initializes a final field in its constructor. The number generator currently returns the placeholder value 1; these classes have no main method.
