# Java Essentials Vol. 2 — versión en español

Esta versión incluye los mismos ejemplos y ejercicios que english, con comentarios, enunciados, guías y mensajes de consola en español.

Se conservan los nombres de carpetas temáticas, clases, métodos y variables para compararlos con el libro y con la versión inglesa. Las palabras del lenguaje Java y las API estándar tampoco se traducen. Todas las referencias internas utilizan espanol.

- [Capítulo 1](chapterone/README.md): fundamentos.
- [Capítulo 2](chaptertwo/README.md): variables, referencias y constructores.
- [Capítulo 3](chapterthree/README.md): paquetes y encapsulación.
- [Capítulo 4](chapterfour/README.md): herencia y sobrecarga.
- **chapterfive/**: jerarquías, conversiones ascendentes y descendentes, y arreglos heterogéneos.

Los ejercicios incompletos conservan su estado: la traducción no los resuelve. Se aclararon dos notas conceptuales: una referencia local no se inicializa automáticamente a null y Object es la excepción a la regla de herencia de Object.

Abre un ejemplo con main y ejecútalo desde tu editor. Para compilar por consola utiliza UTF-8 y mantén la raíz del repositorio como raíz de los paquetes.
