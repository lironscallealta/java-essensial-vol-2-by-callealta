# Capítulo uno: fundamentos de Java

Este capítulo contiene un ejemplo general y su clase de apoyo. Ambos archivos están juntos porque Main utiliza Student.

## Por dónde empezar

Ejecuta Main.java. El programa solicita un nombre y una edad por consola.

## Qué demuestra cada archivo

- **Main.java**: salida por consola, condiciones if, entrada con Scanner, tipos primitivos, operaciones con String, arreglos y creación de objetos Student.
- **Student.java**: campos, constructor con argumentos, constructor sin argumentos y método printDetails().

Los comentarios de Main separan los temas. Answering.java conserva las respuestas personales a las preguntas de la página 51.
