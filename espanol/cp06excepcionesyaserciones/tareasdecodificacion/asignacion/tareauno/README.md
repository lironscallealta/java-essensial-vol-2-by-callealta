# Tarea 1 — Figuras con excepciones

Amplía el ejercicio de figuras del capítulo 5. Lee de uno a tres enteros de la línea de comandos y usa la calculadora de figuras con las dimensiones válidas.

- Lanza `IllegalArgumentException` si recibes una dimensión negativa, ningún argumento o más de tres argumentos.
- Si un argumento no se puede convertir en entero, debe producirse una `NumberFormatException`.
- Captura cada excepción y muestra un mensaje con el problema y el tipo de excepción capturada.
