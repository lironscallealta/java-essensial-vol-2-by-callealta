# Ejercicios de los capítulos

## 1. Saludos según la hora

Dada una hora de 0 a 23, imprime un saludo. Usa «Buenos días» antes de las 12, «Buenas tardes» desde las 12 hasta las 17 y «Buenas noches» desde las 18.

1. Escribe la decisión con `if / else if / else`.
2. Reescríbela con un ternario anidado.
3. Prueba con 9, 12 y 18. Para cada hora, anota qué condiciones evalúa Java antes de elegir el saludo.

## 2. Permisos de archivo

Usa `0001` para leer, `0010` para escribir y `0100` para ejecutar. Ana tiene permiso para escribir y ejecutar.

1. Combina los permisos de Ana con `|` y escribe el resultado en binario.
2. Comprueba cada permiso con `&`. Alinea los bits y marca cada columna que tenga un `1` en ambos números.
3. Usa `!= 0` para imprimir si cada permiso está activado.
4. Agrega el permiso de lectura. Predice qué mensaje cambia y luego ejecuta tu código.
